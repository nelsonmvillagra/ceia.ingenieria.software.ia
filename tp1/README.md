# Tic Tac Toe App

Aplicación web sin sentido que hipotéticamente blockea la pantalla del navegador y para desbloquearla hay que ganarle a la máquina jugando al Ta Te Ti. Si le ganas o perdes mas de 5 veces se desbloquea. El intervalo de tiempo en minutos y entre bloqueos de pantalla es configurable mediante un text box. La aplicación posee además un contador descendente de segundos para mostrar el tiempo que resta hasta el próximo bloqueo.
